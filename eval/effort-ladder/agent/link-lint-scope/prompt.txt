Fix and extend the Markdown link checker. Run `node --test test/public.test.mjs`. `node lint.mjs FILE` reads UTF-8 text and scans inline links of the exact form `[label](target)` on each line; label is nonempty and contains neither `]` nor newline, target is nonempty and contains neither `)` nor newline. Ignore links inside fenced code blocks. A fence is a line whose trimmed text starts with three backticks; it toggles code-block state and is not scanned. Outside fences, report each link whose target starts with `http://` as `LINE: insecure link`, and each target starting with `/` as `LINE: root-relative link`, where LINE is the 1-based source line. Report in source order, one line per violation, including multiple violations on one source line. Other targets are allowed. Exit 1 if there are violations, otherwise 0; stdout contains only reports with a newline after each, and stderr is empty for readable files. An unreadable file or wrong argument count exits 2 with no stdout. Use Node.js built-ins only and do not modify the public test file.
