Export function headingIndex(lines). lines must be an array of strings; otherwise throw TypeError. A heading is a line matching exactly /^(#{1,3}) ([A-Za-z0-9]+(?: [A-Za-z0-9]+)*) *$/; all other strings are ignored. Return an array in input order of {level, title, slug}, where level is the number of # characters, title is the captured words with their original case and single spaces, and slug is title lowercased with spaces replaced by hyphens. Make slugs unique across all headings in this call: use the base slug if unused, otherwise append -2, -3, and so on, choosing the first unused candidate. Previously generated slugs and natural base slugs occupy the same namespace. Do not mutate lines.
