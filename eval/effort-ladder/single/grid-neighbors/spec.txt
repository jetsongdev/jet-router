Export function legalNeighbors(board, row, col). board must be a nonempty rectangular array of nonempty arrays containing only 0 or 1. row and col must be integers identifying a cell inside the board. Reject any invalid input with RangeError, including invalid cells anywhere on the board. A 0 cell is open and a 1 cell is blocked. If the starting cell is blocked, return []. Otherwise return the open orthogonal neighbors as fresh [row, col] pairs in this exact order: up, right, down, left; omit out-of-bounds and blocked cells. Do not mutate board or its rows.
