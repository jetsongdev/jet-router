Export function monthlyOccurrences(start, interval, count, policy). start must be a string in exactly YYYY-MM-DD form representing a valid proleptic Gregorian date from 0001-01-01 through 9999-12-31. interval and count must be safe integers in 1..1200 and 0..1200 respectively. policy must be 'skip' or 'clamp'. Any invalid argument throws RangeError, even when count is zero. Return an array of up to count date strings: inspect exactly count scheduled months, beginning with start's month and then advancing interval months each time. In each month use start's original day: if it exists, emit that date; if not, emit nothing for 'skip' or that month's last day for 'clamp'. Never carry a clamped day into later months. If any of the count scheduled months would fall after December 9999, throw RangeError instead of returning a partial result. Use Gregorian leap-year rules (divisible by 4, except centuries unless divisible by 400), independent of local timezone. count=0 returns [] after validation.
