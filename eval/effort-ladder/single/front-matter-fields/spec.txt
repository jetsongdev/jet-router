Export function parseFields(text). Reject non-strings with TypeError. Split text on LF; a CR immediately before any LF is part of that line ending and is removed, and a terminal CR not followed by LF remains content. If the first line is not exactly ---, return {fields: [], body: text}. Otherwise the next line exactly equal to --- closes the header; if absent throw RangeError. Every header line between delimiters must match /^([a-z][a-z0-9-]*): (.*)$/; reject malformed lines and repeated keys with RangeError. A value is the captured text, including any spaces, and may be empty. Return {fields, body}, where fields is an array of fresh [key, value] pairs in header order, and body is all lines after the closing delimiter joined with LF. Thus recognized headers normalize CRLF to LF in the body; preserve an ending LF through the final empty split line. No YAML interpretation, escaping, trimming, or special keys.
