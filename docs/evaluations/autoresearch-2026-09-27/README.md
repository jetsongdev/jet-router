# Jev 판정 지침 개선 실험

출발 커밋: `90135b3`. [사전 프로토콜](protocol.md), [실험 이력](results.tsv).
[autoresearch](https://github.com/karpathy/autoresearch)의 고정 평가·동일 예산·변경안 채택/폐기 원칙을
Jev 지침 실험에 적용했다. 원본의 모델 학습 실험이나 GPU 성능을 재현한 것은 아니다.

제품의 응답 검증·안전 조건은 수정하지 않았다. 임시 소스 사본에서 shadow effort 지침만 바꿨다.
각 실험은 기존안/변경안을 번갈아 12사례 × 3회씩 호출했다. 기존 12사례는 결과가 노출됐으므로
모두 개발용으로 재분류하고, 새 8사례는 마지막 비교에만 사용한다.

채택 문구는 repository 정보가 없어도 명시적인 편집 범위는 판단할 수 있음을 설명한다.
판정에 충분한 정보와 실제 구현에 필요한 정보를 구분하며, 모델 지원 범위를 확인했다고
간주하지 않는다. 보류·max 보호·후보 검증·취소 동작은 그대로다.

이 점수는 소규모 합성 사례에 대한 사전 가설 일치다. 동일 요청 반복은 독립 표본이 아니며,
3회 반복을 통계적 유의성이나 실제 작업 성공률의 근거로 사용하지 않는다. modelRequested는
jev-latest이며 반환 버전·실제 청구액·토큰 사용량은 미확인이다. 비용 절감 역시 검증하지 않았다.


## 결과 및 중단

| 실험 | 비교 가설 | 기존 일치 | 변경안 일치 | 처리 |
| --- | --- | --- | --- | --- |
| 1 | 판단 정보와 실행 정보 구분 | 33/36 | 36/36 | 채택 |
| 2 | keep과 동일 참고값 추천 구분 | 36/36 | 27/36 | 폐기, 연속 1회 |
| 3 | host 불확실성과 작업 난도 구분 강화 | 36/36 | 36/36 | 폐기, 연속 2회 |
| 4 | 위험한 주제와 실제 실행 행위 구분 | 36/36 | 36/36 | 폐기, 연속 3회 |
| 최종 | 원본 대 채택안, 새 8사례 | 24/24 | 24/24 | 회귀 없음, 추가 조정 없음 |

총 336건 호출, 모든 호출 성공, 재시도 없음. 첫 실험의 불필요한 keep은 3→0건이었고
필수 keep 누락은 모든 arm에서 0건이었다. 두 번째 변경안은 동시성·진단·timeout 사례를
medium으로 낮춰 9건 불일치가 발생했다. 이를 채택하지 않았다.

첫 변경안 채택 후 3회 연속 의미 있는 개선 없음으로 중단했다. 개선 폭은 개발 데이터에서
3/36(8.33%p)이며, 새 holdout에서는 향상이 아닌 동률이었다. 일반적인 품질 향상·완전성·
실제 작업 성공률을 보장하지 않는다. 단순 작업의 불필요한 keep 감소 근거만 확보했다.

## 반영 및 재현

`src/harness.js`에 첫 변경안의 추가 문구만 반영하고 criteriaVersion을
jev-effort-provenance-v3로 올렸다. legacy 요청과 전송/응답 검사에는 변경이 없다.
채택안 실호출의 모든 요청 해시가 현재 제품 요청과 일치하는지 자동 테스트로 검증한다.

baseline-harness.txt는 실험 당시 원본이며 runner가 임시 사본에만 적용한다.
01–05 설정 JSON과 결과 JSON을 보존했다. 현재 커밋의 다른 요청 구성/전송 코드도 함께 사용해야
동일한 요청을 재현할 수 있다. 향후 코드·Jev 버전 변경 시 점수의 동일한 재현을 보장하지 않는다.

```sh
node scripts/research-quality.mjs \
  docs/evaluations/autoresearch-2026-09-27/01-scope.json \
  /absolute/path/to/.env /tmp/new-research-result.json
```

위 명령은 최대 72건의 유료 외부 호출을 새로 수행한다. 자동 회귀 명령이 아니며 재실행 범위를
정한 뒤 사용한다. 기존 출력 경로가 있으면 호출 전에 거부한다. 비밀과 원시 응답은 결과에 없다.

공통 84개·MCP 29개·Claude 오프라인 hook 2개와 manifest strict 검증 모두 종료 코드 0으로 통과했다.
Claude 실제 UI·enforce·실제 작업 성공률 비교는 남아 있다.
