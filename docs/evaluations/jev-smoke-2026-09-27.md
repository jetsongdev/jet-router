# Jev 합성 입력 1차 실호출

상태: **12건 실호출 완료**, enforce 승인·전체 품질 평가 완료를 의미하지 않음.

## 범위와 재현 정보

사용자가 다음 평가 진행을 요청하고 프로젝트 루트 `.env`의 `TYPESAFE_API_KEY`를 사용하도록 지정했다. 해당 키만 파싱했고 쉘 source, 다른 환경변수 로딩, 플러그인 설치·설정 변경은 하지 않았다. 키 값·개인 프로젝트 원문은 보고서에 없다.

- 기준 코드: `1448256`; 실행 시 추가한 평가 runner/fixture의 SHA-256은 [JSON 결과](jev-smoke-2026-09-27.json)에 기록.
- 명세: `effort-router-sdd-01` / `73bb4001ba941b1510e4c02b71a8f7b662023eb2`.
- 입력: [합성 사례 12개](../../eval/jev-smoke.mjs), 한국어 중심 + 영어 1개. 실제 운영 삭제·배포 요청이 아니라 분류용 가상 문장이다.
- 실행: `node scripts/evaluate-jev.mjs --live --key-file ../../.env` → exit 0.
- 최대 12회, 순차 1회씩, retry/fallback 없음. 통신·schema 오류가 발생하면 첫 오류에서 중단하도록 고정.
- 평가 runner는 제품과 같은 helper를 실행했다. Claude의 실제 UI·hook·secure storage 경로는 이 실호출에 포함되지 않았다.
- 요청 모델은 제품과 같은 `jev-latest`. helper가 응답 모델 문자열을 보존하지 않으므로 실제 응답 버전은 unknown이다. 토큰과 실제 청구액도 unknown으로 기록한다.

공식 [모델 문서](https://docs.typesafe.ai/models)를 2026-09-27 확인했다. 입력 $0.042/백만 토큰, 출력 무료, 요청당 64k 토큰 기준이다. 12건이 각각 64k 입력 토큰인 가정의 계산액은 $0.032256이다. 이는 단가 기반 보수적 계산이며 청구 상한 보장·실제 계정 요금 확인이 아니다. 현재 호출은 이 12건에서 종료했다.

## 발견과 다음 단계

맥락 충분 점수가 명확한 오타/일반 구현에서 0.38~0.40, 맥락 없는 후속 지시에서 0.58, 긴 후속 지시에서 0.55였다. 현재 질문 문구가 실제 작업 평가에 필요한 맥락을 일관되게 구별하는지 추가 검토해야 한다. 이 결과를 보고 임의로 0.5 임계값을 정하거나 점수 방향을 뒤집지 않았다.

운영 삭제 입력의 위험 점수는 0.96, 삭제 전 검증 이유 설명은 0.08이었다. 두 사례만으로 위험 판별의 calibration·정확도를 판단하지 않는다. 추천 effort가 높아도 작업 실행 승인이 되는 것은 아니다.

다음은 비민감 Claude 세션에서 실제 플러그인 설정·요약 표시·원래 effort 유지 확인, 별도 holdout과 반복 평가, 맥락 질문/기준 검토다. enforce는 그 이후에도 정책 임계값과 실제 요청 전달 검증이 필요하다. local provider 비교·고정 effort 대비 품질/토큰/비용 비교는 미실시다.

## 개발 검증

- `node scripts/evaluate-jev.mjs --dry-run`: exit 0, 호출 0, 키 읽기 0. 입력/요청 해시와 크기만 출력.
- `npm test`: exit 0, Node 43개.
- `npm run test:hooks`: exit 0, fake/Jev mock 각 1개.
- `npm run validate`: exit 0, 두 manifest strict 검증.

개발용 runner의 `.env` 입력 지원은 플러그인 런타임 설정과 별개다. 사용자는 `/plugin` → Installed → jet-router → Configure options에서 provider/전송 동의/키를 설정한다. 플러그인은 `.env`를 자동으로 읽지 않는다.
